# Initial public release

This release collects the tested rooted/custom-ROM workaround modules used to make the official Google Play Store available as the privileged `com.android.vending` base on LineageOS for microG, optionally restrict Play Store networking while preserving the tested Integrity path, and repair Play installer provenance for legitimately owned apps.

Assets:

- `playstore_base_module_source.zip` — source-only builder; does **not** contain Google's Play Store APK.
- `playstore_xray_privacy_filter-v1.2-arm64.zip` — ARM64 per-UID default-deny Play Store network filter using Xray-core v26.9.9 downloaded and verified at install time.
- `play_provenance_repair-v1.1.6.zip` — APatch WebUI/CLI provenance repair helper.
- `SHA256SUMS` — checksums generated by the release build.

These are empirical compatibility tools for rooted custom ROMs, not a fix for the underlying Play Integrity policy affecting official/unrooted alternative Android operating systems.
